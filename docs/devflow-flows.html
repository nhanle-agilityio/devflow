Một ý tưởng đi qua plugin như thế nào

Chấm sáng là một ý tưởng đang di chuyển. Nó chỉ dừng lại chờ ở các ô màu cam: merge spec (Gate 1), merge PR (Gate 2: merge gate với risk:low, bạn với risk:high) và publish release (bạn). Sau Gate 2, accept → release kiểm tra những gì đã ship rồi cắt release.

Merge: risk:low tự merge khi check xanh, risk:high chờ bạn

Claude không bao giờ merge. Action devflow-merge-gate duyệt các PR gắn devflow, cũ nhất trước, và merge tối đa một PR mỗi lần chạy. Mọi PR do cổng merge đều được đánh dấu để release và report phân biệt với người. Mặc định tắt, chạy thử (dryRun) trước.
